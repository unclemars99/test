# D000g — Explicit physical phase did not improve the raw-patch representation

## Experiment

E000-G tested the revised hybrid Process Token hypothesis on the same raw PHM2010 force signals.

Three representations used identical raw waveform boundaries, token counts, encoder architecture, VICReg objective, LOCO split and five seeds:

- Fixed Raw: `[Fx, Fy, Fz, 0, 0]`
- Hybrid Phase: `[Fx, Fy, Fz, sin(phi), cos(phi)]`
- Hybrid Random Phase: `[Fx, Fy, Fz, sin(phi+delta), cos(phi+delta)]`

The only intended manipulated variable was access to the recovered physical spindle phase.

## Main evidence

Mean LOCO R2:

- Fixed Raw: **0.347**
- Hybrid Phase: **0.225**
- Hybrid Random Phase: **0.241**

Worst-fold R2:

- Fixed Raw: **0.172**
- Hybrid Phase: **0.087**
- Hybrid Random Phase: **0.017**

Hybrid Phase beats Fixed Raw in 0/3 held-out cutters and in 0/5 seed-level mean comparisons.

The pre-registered gate therefore returns **NOT_SUPPORTED**.

## Decision

**H002f is NOT SUPPORTED by E000-G.**

The narrow claim rejected is:

> Simply appending `sin(phi), cos(phi)` physical spindle phase channels to each raw local patch improves cross-domain shared-representation learning.

This does not invalidate physical process structure in general. It does invalidate a second concrete implementation after hard phase normalization also failed.

## Interpretation

Two consecutive results now constrain the search space:

1. replacing raw time structure with hard phase-normalized cycles hurts transfer;
2. naively appending instantaneous phase channels to the same local CNN input also hurts transfer.

Therefore the next Process Token test should not keep changing local waveform alignment or adding phase as another raw channel. If H002 is pursued further, physical structure should be introduced at a higher structural level, such as ordered tooth/revolution composition, stage hierarchy, or as a prediction/attention relation rather than an input-channel decoration.

## Research status

- H002c_1: SUPPORTED — the coordinate is observable.
- H002c_2: NOT SUPPORTED — hard phase-normalized tokenization fails.
- H002f: NOT SUPPORTED — raw + phase-channel hybrid fails.
- H002 overall: OPEN but materially weakened for local phase-based tokenization.

## Next

Do not tune the failed phase-channel design. The next useful falsifiable question is whether **ordered physical composition** adds information beyond local token content (H002e), using the same local raw tokens but changing only the higher-level aggregation/order structure.
