# D000h — Hard phase-normalized Process Token does not beat Fixed Patch on E000-F v2

## Experiment

E000-F v2 is the corrected decisive run after the phase-origin issue in v1 was pre-registered and fixed before inspecting v1 metrics.

Data and protocol:

- 45 ordered raw PHM2010 cuts: 15 each from C1/C4/C6;
- force channels Fx/Fy/Fz;
- 128 tokens/cut;
- 288 samples/token;
- strict 3-fold leave-one-cutter-out;
- identical position-sensitive CNN token encoder;
- identical token-level VICReg objective;
- identical 5 seeds;
- identical frozen Ridge wear probe.

Representations:

1. `fixed_patch`: 288-sample contiguous sampling patches;
2. `process_token`: true spindle-cycle segmentation using a common analytic-phase crossing, each physical revolution resampled to 288 points;
3. `random_phase`: same physical-cycle segmentation as Process Token but with a deterministic random phase rotation per cut.

## Pre-registered H002c_2 gate

Process Token had to:

1. beat Fixed Patch mean LOCO R2 by >= 0.05;
2. not worsen the worst fold;
3. beat Random-Phase mean LOCO R2 by >= 0.05;
4. beat Fixed Patch in at least 2/3 fold means;
5. beat Fixed Patch in at least 4/5 seed-averaged comparisons.

## Results

Aggregate mean LOCO R2:

- Fixed Patch: **0.400**;
- Process Token: **0.177**;
- Random-Phase: **0.084**.

Worst-fold mean R2:

- Fixed Patch: **0.266**;
- Process Token: **0.029**;
- Random-Phase: **-0.218**.

Fold means:

- held-out C1: Fixed 0.266, Process 0.306, Random 0.094;
- held-out C4: Fixed 0.581, Process 0.029, Random -0.218;
- held-out C6: Fixed 0.353, Process 0.196, Random 0.377.

Process Token therefore loses to Fixed Patch by **-0.223 mean R2** and beats Fixed Patch in only 1/3 folds. It beats Random-Phase by **+0.093 mean R2**, satisfying only the phase-control criterion.

All pre-registered criteria except `Process > Random-Phase by >=0.05` fail.

## Decision

**H002c_2, in its current hard-alignment form, is NOT SUPPORTED by E000-F v2.**

This is a useful falsification, not a failure of the research program.

The data support a narrower statement:

> A common physical phase reference contains useful information relative to an arbitrary phase origin, but replacing sampling-coordinate patches with hard phase-normalized revolution tokens removes or distorts enough state information that the overall representation transfers worse than Fixed Patch.

## Interpretation

The result argues against defining Process Token as `raw waveform -> phase-normalized waveform only`.

Hard alignment changes two things at once:

- it exposes a common physical coordinate;
- it normalizes away local timing / phase-drift information and imposes a cycle boundary.

The Fixed Patch result suggests that some of the information removed by hard normalization is useful for wear/state transfer.

This points back to the more general Process Token definition already considered for ultrasonic welding:

`Token = [raw local signal, physical coordinate, process/stage identity, duration/other physical anchors]`.

In other words, the physical coordinate should be tested as **additional structure**, not necessarily as a replacement for the sampling coordinate.

## New hypothesis

### H002f — Hybrid Process Token

A hybrid token that retains the raw local waveform while adding an explicit physical process coordinate will transfer better than either:

- raw Fixed Patch alone; or
- hard phase-normalized Process Token alone.

The next experiment should hold the raw patch unchanged and add phase information as explicit `sin(phi), cos(phi)` channels under a parameter-matched encoder. This directly tests whether physical coordinate information helps without deleting raw timing structure.

## Scope guardrail

E000-F does not test:

- hierarchical Revolution -> Tooth token composition;
- ordered token-sequence modeling (tokens are mean/std pooled);
- modality-dependent coordinates;
- multimodal fusion;
- industrial ultrasonic-welding stage tokens.

Therefore H002 overall remains OPEN, but the simple hard-alignment variant has been falsified on this benchmark.
