# D000f — A real physical process coordinate is recoverable from raw PHM2010 force signals

## Experiment

E000-E audited 21 representative raw PHM2010 cuts: C1/C4/C6 × cuts 1, 50, 100, 150, 200, 250, 315. Each raw file was downloaded from the public Kaggle mirror at execution time and kept ephemeral; only audit summaries were committed.

The audit used the known milling priors:

- sampling rate 50 kHz;
- spindle speed 10,400 RPM -> 173.33 Hz;
- 3-flute cutter -> tooth-passing frequency about 520 Hz.

For each cut, the central signal region was examined with Welch PSD on force channels, followed by narrow-band Hilbert phase recovery around the strongest physically plausible peak.

## Pre-registered gate

PASS required, for a coordinate:

- >= 80% successful cuts;
- median physical-frequency error < 5%;
- >= 80% of cuts with frequency error < 5%;
- median cycle-length CV < 5%;
- median positive phase-increment ratio >= 95%.

## Results

### Spindle coordinate

- success: 21/21 cuts;
- median frequency error: 0.356%;
- fraction below 5% error: 100%;
- median cycle-length CV: 0.435%;
- median positive phase-increment ratio: 99.887%;
- median spectral prominence: 3,758.

Result: **PASS**.

### Tooth-passing coordinate

- success: 21/21 cuts;
- median frequency error: 0.356%;
- fraction below 5% error: 95.24% (20/21);
- median cycle-length CV: approximately 0% after phase locking/resampling diagnostics;
- median positive phase-increment ratio: 99.970%;
- median spectral prominence: 80,493.

Result: **PASS**.

The main exception is C1 cut 1, where the strongest tooth-band force peak was about 590.27 Hz (13.5% from the 520 Hz prior). C6 cut 1 also shows weaker tooth-cycle stability than mature cuts. Therefore early-cut behavior should remain an explicit robustness case rather than being silently removed.

## Interpretation

The evidence supports a hierarchical physical coordinate in PHM2010 force observations:

`spindle revolution -> three tooth-passing subcycles`.

The spindle coordinate is the more uniformly reliable global coordinate across all 21 audited cuts. The tooth-passing coordinate is much more spectrally prominent in most cuts and is a strong candidate for the local Process Token unit, but it has an early-cut edge case.

This is stronger than the previous synthetic sanity check because the coordinate was recovered directly from ordered real 50 kHz signals across three cutters and multiple lifecycle locations.

## Decision

**H002c_1: SUPPORTED on this representative PHM2010 force-signal audit.**

**H002 / H002c_2 remain OPEN.** Recoverability of a physical coordinate does not imply that tokenizing on it improves shared representation.

The next falsifiable experiment must compare, on the same raw cuts and with the same encoder/objective/model budget:

1. Fixed Patch + VICReg;
2. phase-aligned Process Token + VICReg;
3. a phase/random-order negative control where practical.

Only a stable cross-cutter advantage for the process-aligned condition can support H002c_2.

## Additional methodological note

The previously surfaced `originfeature/data_x*.npy` arrays cannot be used for this claim because their 5,000 samples were generated by random sampling without replacement, which destroys time order. The raw Kaggle CSV route resolves that confound.
